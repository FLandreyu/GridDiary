# 占位图片目录（全部可选）

把图片放进本目录后页面会自动使用；**一个都不放也能正常跑**（都有 emoji / 渐变兜底）。

下面的尺寸不是估的，而是把组件里「图片实际被渲染出来的像素框」量出来后反推的（1440×900 视口实测），
**比例对上就不会被拉伸或裁掉主体**。

## 三、每张图怎么画才不会被裁坏

- **`hero.png`（重点）**：横幅用 `cover` 且随窗口变形，所以
  - 主体要**横向居中**——窄窗口（≤960px）时左右会被裁掉；
  - 主体纵向放在 **18% ~ 70%** 之间：底部约 **88px（≈19%）被波浪层盖住**，最上面约 56px 被固定顶栏盖住；
  - `object-position: center 30%` 表示纵向裁切时偏向保留靠上部分，**别把重点放在最底部**。
- **`cover-placeholder.png`**：网格卡是 1.13:1、列表卡是 1.46:1，而这两处的 `<img>` 只设了 `width/height:100%`、**没有 `object-fit`**，图片会被非等比拉伸。取 4:3 作折中，两边失真都在 15% 以内；图案请**居中、四周留 ≥8% 余量**。
  > 想彻底免疫：给 `.cover-img` / `.thumb-img` 补上 `object-fit: cover`，之后任意比例都能用。
- **`auth.png`**：`contain` 不裁切、只是留白，所以竖长图也不会变形，只是窄一些；想刚好铺满 150×140 就用 ≈1.07:1。
- **`logo.svg`**：正方形，圆角由 CSS 给（顶栏 9px、页脚 8px），**图内不要再画圆角或描边**；浏览器标签页图标是另一个文件 `public/favicon.svg`。
- **`auth.png` 的圆角**同样由 CSS 给（18px），也**不要在图片里画框/圆角/白底**。
- **头像**：一律圆形，主体别贴边（留 10% 内边距），背景透明或纯色最稳。

## 四、命名与引用约定

- 引用路径统一写 `/images/xxx.png`（放在 `public/images/` 下即可，无需 `import`）；
  模板里必须**动态绑定**：`:src="'/images/xxx.png'"`，写成静态 `src` 会让 `vite build` 报错。
- 文件名必须与上表**完全一致**，组件是按固定文件名去找图的。
- 加载失败都有兜底：`hero` 退化成渐变、`auth` 退化成 ✨/🌸/🔑、无封面退化成 📔。
- 建议用透明背景的 PNG/WebP，风格与紫粉渐变主题协调（二次元 / 清新风）。

## 五、用户上传的图片不在这里（顺带说明）

首页 / 详情 / 相册里的日记配图走的是上传接口，由后端 `ImageStorage` 生成两份：
原图存 `upload/original`，缩略图存 `upload/thumb` 并**等比缩到最长边 400px**（`THUMB_MAX_EDGE`）。

- 详情页九宫格：150×150；相册列宽：约 276px（1440px 下 3 列）
- 所以**上传原图长边建议 ≥1200px**；400px 的缩略图在 2× 屏上刚好够用，不用自己准备缩略图
